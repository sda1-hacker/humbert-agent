# 模块化重构说明

本次调整保留现有功能与持久化格式，沿用 Eino、Runtime、Registry、Permission 和模块装配入口；不引入新的插件框架或第三方 Backend。

## 已完成的调整

| 范围 | 当前职责 |
| --- | --- |
| Skill 目录 | `frontend/src/stores/skills.js` 统一规范化、Agent 引用、加载状态、请求合并与强制刷新；页面保留选择和草稿 |
| Skill 详情 | `SkillDetailView` 管详情与别名/删除；`SkillSourcePanel` 管更新/重装/来源；`SkillFileTree` 管目录展开；`useSkillFiles` 管预览与过期响应 |
| 受控执行 | `builtin/process.go` 共用超时、Runner 调用和结果组装；`process_output.go` 共用限长输出；命令/脚本保留各自的输入和权限策略 |
| 消息投影 | `multimodal/content.go` 提供正文、结构化文本和 reasoning 读取；上下文仍显式保留原来的空白处理 |
| 工具目录 | `tools/catalog.go` 收拢类别、文案与默认选择；新增工具可通过 `Descriptor.Display` 提供展示元数据 |
| 文件操作 | `internal/fileops` 拥有 Backend、路径访问、遍历、文件锁和原子提交；只捕获文件策略与限制 |
| 浏览器/桌面 | 分别位于 `tools/browser`、`tools/desktop`；截图仅依赖 `tools.ImageWriter`；网页拨号共用 `publicweb` |
| RAG | `ingestion.go` 拥有版本、阶段与失败收尾；`ingestion_document.go` 处理原件/文档/切分；`ingestion_batch.go` 构造分块批次 |
| 知识库业务 | `knowledge` 分为模块构造、设置、连接生命周期、导入任务、文档查询和 Agent 工具 |
| 应用启动 | App 按 runtime → tasks → modules 装配；仍使用同一份三阶段资源清理清单 |

移除了只有 package 声明的空 Go 文件，以及命令工厂不使用的 WorkspaceManager 依赖。项目依赖文件未更改。

## 保留的边界

- 157 个导出服务方法签名与重构前一致，既有 DTO 字段保留；BuiltinToolDTO 仅新增 `defaultEnabled`，让前端使用后端目录的默认选择。
- JSONL、SQLite、Agent 配置和审批 checkpoint 的格式保持不变，无需数据迁移。
- 文件访问仍经 PathGuard + os.Root；文件锁、冲突检测、原子写入和扫描限制保留。
- 命令继续使用程序与 argv，环境变量不隐式继承宿主；Skill 暂存、身份检查和只读进程策略保留。
- Runtime 实时状态与 Session 历史消息继续分别管理。

## 代码量

统计物理行，包含注释、空行和 Vue 样式；计入新增文件，不包含文档、生成资源、依赖目录或临时回归用例。

| 范围 | 重构前 | 重构后 | 变化 |
| --- | ---: | ---: | ---: |
| internal 中的 Go | 73,378 | 73,443 | +65 |
| frontend/src 中的 Vue/JS | 30,268 | 29,664 | -604 |
| 合计 | 103,646 | 103,107 | **-539** |

后端拆分增加了少量包定义与显式依赖，主要收益是职责与修改范围更清楚；不能把文件迁移算成删除业务代码。前端减量包含目录逻辑合并与过度换行整理。

## 验证

已通过：

- `go build ./cmd/... ./internal/... ./examples/...`；保留环境原有的 macOS 链接警告。
- `go vet ./...`、`git diff --check` 和前端 `npm run build`。
- 临时 Go overlay 回归与 race：文件分页、编辑、越界、符号链接、大小限制、取消和并发原子写入；执行输出、超时、取消、非继承环境；脚本结果扁平 JSON；消息正文与 reasoning 投影。
- RAG 16 个普通/父子切分场景与重构前响应、分块和错误一致；另检查解析、切分、索引失败的版本和状态收尾。
- 前端临时回归：Skill 请求合并、强制刷新、旧响应拒绝、失败后恢复、预览切换和销毁。
- Vue 渲染对照：无效 Skill 的来源展示与重构前一致；文件树默认展开；拆分后的三个组件保留全部 107 条原样式规则。
- AST 核对导出服务方法签名与既有 DTO 字段。

临时用例位于本次会话的系统临时目录，遵循现有工程规范，没有恢复仓库内的测试目录。未连接真实模型或 PostgreSQL，也未执行真实浏览器、桌面输入或 Wails GUI 人工验收；编译和临时回归不代表这些外部集成已实测。

## 后续扩展入口

新增普通业务能力继续使用 `app.WithModules` 和 `runtime.CapabilityProvider`，由模块拥有自己的配置、连接和 Agent 绑定；工具由宿主统一保护。可从 `examples/modules/textstats.go` 入手。新增内置工具在 Factory 中声明能力与展示元数据，并在 App 装配点注册；复杂的工具轨迹展示仍由专属前端适配处理。
